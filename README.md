## If you can imagine it, we can build it.

**A team of developers, media makers and problem-solvers based in Hampshire, UK.**

We work where code meets creativity: building web tools, browser extensions, scripts, media workflows, 3D visuals and the occasional desktop utility. That's quite a mix. It keeps the coffee machine guessing.

Many projects start with a practical problem. We try to turn it into something clear, useful and dependable — while keeping the "one quick extra feature" from becoming an entirely separate project.

---

## What we do

- **Web development** — WordPress, WooCommerce and custom Gutenberg blocks
- **Developer tools** — scripts, command-line utilities and workflow automation
- **Media technology** — tools for handling, organising and processing images and video
- **Creative production** — product visualisation, 3D modelling, animation and motion graphics
- **Small applications** — focused utilities that solve a specific problem without getting in the way

We enjoy joining up the visual and technical sides: working out how something should look, then building the tools and systems that make it work.

## Selected projects

- [Advanced Link Block](https://github.com/Scerno/Advanced-Link-Block) — make a whole Gutenberg block clickable, with support for links, downloads, email and phone actions.
- [CleanUp LinkedIn](https://github.com/Scerno/CleanUp-LinkedIn-Chrome-Extension) — a lightweight browser extension for tailoring the LinkedIn feed and layout.
- [MouseFeeder](https://github.com/Scerno/MouseFeeder) — a Python utility that turns mouse and keyboard input into a virtual joystick.
- [Media Management Tools](https://github.com/Scerno/Media-Management-Tools) — command-line helpers for everyday media tasks.

## Tools across our work

`PHP` · `JavaScript` · `Python` · `WordPress` · `WooCommerce` · `Git` · `FFmpeg` · `ImageMagick`

For visual work, we use **Adobe Creative Cloud**, **Cinema 4D**, **Blender**, and whichever tools best fit the project. We try not to make the software list longer than the project.
